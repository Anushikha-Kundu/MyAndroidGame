# ToDoApp 📝

A clean and simple Android To-Do application built to help users manage their daily tasks efficiently. The app features a modern UI with swipe-to-action functionality and persistent storage using SQLite.

## ✨ Features

*   **Add Tasks:** Quickly add new tasks via a modern bottom sheet dialog.
*   **Persistent Storage:** Uses SQLite to ensure your tasks are saved even after closing the app.
*   **Swipe Actions:**
    *   **Swipe Right:** Edit an existing task.
    *   **Swipe Left:** Delete a task with a confirmation dialog.
*   **Task Management:** Mark tasks as completed or pending with checkboxes.
*   **Splash Screen:** A smooth entry experience with a dedicated splash activity.
*   **Material Design:** Built using Material Components for a polished look and feel.

## 🛠️ Built With

*   **Java** - Primary programming language.
*   **SQLite** - Local database for data persistence.
*   **RecyclerView** - To efficiently display the list of tasks.
*   **ItemTouchHelper** - To handle swipe-to-edit and swipe-to-delete gestures.
*   **Material Design Components** - For UI elements like Floating Action Button and Dialogs.
